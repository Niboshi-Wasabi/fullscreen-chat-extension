## ログ種別と判定

| 種別 | 代表メッセージ | 製品拡張との関係 | 判定 |
|---|---|---|---|
| A. content 終了タイムアウト | `Script terminated by timeout` | YouTube ナビ購読の個別解除が長いと発生。AbortController 一括解除後、合成 20 シナリオ×2 で **0 件** | **解消（回帰対象）** |
| B. Conduits RunListener | `Actor 'Conduits' destroyed before query 'RunListener' was resolved` | **最小診断拡張**（storage 通知で iframe 破棄のみ、製品コードなし）でも 10 回操作で同種が複数行。製品固有ではない | **Firefox / BiDi＋拡張フレーム破棄のノイズ寄り。隠蔽パッチ禁止** |
| C. PictureInPictureChild dead object | `can't access dead object`（PiP actor） | 同上の最小拡張でも出現。製品の Document PiP 実装を触っていない構成 | **Firefox 内部。製品因果なし** |
| D. ContentPrefs shutdown | `Actor 'ContentPrefs' cannot send message ... during shutdown` | 修正後の製品合成 run の shutdown 警告に残存。**拡張なし**の全画面入退場・タブ破棄 3 回では **未再現** | **拡張または BiDi プロファイル条件の疑い。未確定。機能失敗は未観測** |
| E. Remote Agent context null | `can't access property "id", context is null` | BiDi 終了付近。機能アサーション成功後 | **テストハーネス／Remote Agent 寄り。手動終了との比較が残る** |

## 残作業（優先度順）

1. **手動通常終了比較（高）** — **未実施（2026-11-15）**  
   専用プロファイルで製品拡張を読み、BiDi を使わずタブを人手で閉じる。stderr / about:logging 相当で D・E が出るか記録。出なければ「BiDi／自動化経路限定」と ISS-015 を条件付きクローズ候補にする。自動化セッションではデスクトップ Firefox の対話操作を完了していない。
2. **ContentPrefs 最小再現（中）**  
   storage だけ／content だけ／windows 別窓あり、の最小拡張を分け、D の必要十分条件を特定。
3. **合格基準の明示（中）** — ISS-005 決定に合わせ、公開判定は「A=0 かつ機能失敗なし」を必須、B/C 単独不合格にしない方針でよい（オーナー 2026-11-15 品質目標採用）。最終クローズは手動比較後。
4. **製品パッチ**  
   A 再発時のみ。B/C を消すための待機延長やログ抑制はしない。

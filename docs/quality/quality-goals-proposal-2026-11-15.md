## 推奨たたき台

| 項目 | 提案 | 根拠・注意 |
|---|---|---|
| 最低 Chrome / Chromium 系 | **Chrome 121+** を保証の主対象。Edge は「同一メジャーで煙テスト」 | Firefox 121 と揃える。それ未満はベストエフォート |
| 最低 Firefox | **121.0**（現行 manifest を維持） | 下げる理由がなければ据え置き |
| Chromium 製品別 | 署名済み Google Chrome を E2E 正。同梱 Playwright Chromium は ISS-012 解消まで必須ゲートにしない | |
| OS | Windows 10/11 を公開初版の保証。macOS は将来 | 既存 ISS-005 確定事項 |
| 同期許容（アーカイブ／タイムシフト） | 表示が再生位置から **±2 秒**以内を「合格目安」。測定は実メディア 3 シークの中央値 | 既定 `maxSkewSec` と一致。厳格 SLA ではない旨を README に書く |
| パネル表示上限 | `filter.maxVisible` **100** を維持。100 超は古い行を落とす | 既実装 |
| 負荷（定性） | 合成 100 件バーストで UI 操作（トグル・入力フォーカス）が 2 秒以内に応答 | ISS-013 の再測定を承認後に公式化 |
| メモリ | 30 分ライブ相当の合成受信後、拡張の明らかな単調増加リークがない（ヒープ差分は参考） | 厳密な MB 上限は初版で設けない案 |
| アクセシビリティ | 自前 popup/options は axe 自動＋キーボード到達を維持。スクリーンリーダーは「重大な読み上げ欠落がない」定性 | 正式 WCAG 適合宣言はしない案 |
| 実 IME | 日本語 IME で変換中誤送信ゼロ（手動必須） | 合成 `isComposing` では代用完了にしない |
| Document PiP | 対応ブラウザで成功することを **推奨経路**。失敗時 OS 別窓フォールバックを許容し、PiP 必須とはしない | `alwaysOnTop` の天井を文書化済みの方向 |

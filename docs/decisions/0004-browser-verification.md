# ADR 0004: 合成データによる拡張E2Eと明示的なChromeモード

- 日付: 2026-11-14
- 状態: ローカルChromeで実証。同梱Chromium/CI/Firefoxは未実証。
- 関連: [Phase 5計画](../plans/2026-11-14-browser-verification.md)、[運用](../operations/browser-verification.md)。

## 決定

Playwright 1.65.0とaxe 4.14.0を固定し、テストごとに専用プロファイルを使い、本番用ビルドの拡張機能を読み込む。1.65.1は公開待機期間に抵触したため採用せず、待機期間例外を増やさない。

CIは同梱Chromiumを必須とする。一方、端末のWindowsコード整合性ポリシーが同梱Chromeのchrome_elf.dllを拒否したため、ローカルでは署名済みChromeを明示的に選べる方式を追加した。暗黙の代替やOSポリシーの変更は行わない。結果にチャネル・実バージョンを記録する。

実サイトの不安定性やアカウント依存を避け、許可済みYouTube URLへ合成DOMを配信する。storageとcontent scriptは実物を使い、製品コードにテスト専用APIを作らない。Firefoxや他サイトの保証へ拡張しない。

## 発見した問題への対応

E2E/axeが検出した42入力の読み上げ名欠落は、可視ラベルとaria-labelledbyを静的に結合して修正。明色の選択カテゴリは既存の前景色を使いコントラストを修正。Material Symbolsの欠落グリフは、使用中26アイコンで同梱フォントを再取得し、出典・SHAとApacheライセンスを記録した。機能仕様や外部通信先は変えない。

## トレードオフ

固定ブラウザは再現性が高いが、端末の実行ポリシーによる制約がある。インストール済みChromeは署名済み実製品で確認できるが、端末の更新で版が変わる。両者を混同せず、CI実行を別途確認する。

合成DOMは実サイト互換性を保証しない。axeは手動確認を置き換えず、観測値は未決定の品質数値を確定しない。失敗時のtrace/画像/ログを保存し、未検証を隠さない。

# ADR 0002: ローカル検証の実行可能な入口

- 日付: 2026-11-14
- 状態: Phase 3で採用・実装。
- 関連: [ADR 0001](0001-harness-foundation.md)、[実装計画](../plans/2026-11-14-verification-foundation.md)。

## 決定と理由

- Vitest 5.1.0 + WXT 0.21.5の公式連携を使い、ブラウザ API は fake-browser を使って結合検証する。実ブラウザでの動作は別途確認する。
- ESLint 10.14.0 + typescript-eslint 8.72.2、Prettier 3.10.1、dependency-cruiser 18.7.2、YAML 2.9.1を固定。ESLint 10.15.0は導入時に待機期間例外を生成したため採用せず、例外なしで解決できる10.14.0を選んだ。pnpmの自動例外は残さない。
- Node要件とpnpm版はpackage.jsonへ、依存解決はlockfileへ記録。WXT/TypeScriptの既存依存指定は保持する。
- Nodeから各CLIを直接起動し、最初の失敗で停止・未実行を記録する。PowerShellやcmd固有の連結・シェル展開に依存しない。
- 既存の2キー×42言語の英語フォールバックは限定リストで可視化し、翻訳を捏造しない。新たな不足・古い例外は検出する。
- 現行manifestを回帰基準として保存するが、既存PRDとの不一致を承認したとは扱わない。

## 代替案とトレードオフ

Node標準テストだけなら依存を減らせるが、現行TS/WXTの型・自動import・ブラウザAPI連携を別途整える必要がある。独自の依存グラフ検査器より、既存ツールのパス解決と動的import検査を使う。

formatの初期適用でsrcの25ファイルに書式差分が生じた。作業前コピーを同じPrettier設定で変換した結果と全件一致した。生成物・外部コピー・Markdownの書式一括変更は対象にしない。

検査器にも負例を用意するが、文書の意味、API別名の追跡、実ブラウザ挙動、完全な設定入力検証は別途レビューが必要。セキュリティ検査・CI・E2Eは次フェーズとし、統合コマンドだけで公開可能としない。

# プロダクト要件定義（PRD）— 凍結版

状態: **凍結（2026-11-14）／改訂 2026-11-15（ISS-001/002/018/019/020）、2026-11-16（ISS-027）、2026-11-23（ISS-034）**  
[競合評価](./competitive-evaluation.md)で特定した主な不足 10 件をもとに、要件を定義した。実機評価や公開前の仕様判断で矛盾が見つかった場合に限り、要件を改訂し、理由を末尾に記録する。

---

## 1. プロダクト目標

全画面で映像を見ながら、チャットを読んだり、コメントを投稿したり、不要な投稿をフィルタで隠したりできるようにする。チャット表示で映像を大きく覆わないようにする。

YouTube（ライブ、プレミア公開、チャットリプレイ付きアーカイブ）と Twitch（ライブ、VOD）で、同じ拡張機能を使い、共通の操作でチャットを扱えるようにする。

---

## 2. ターゲットユーザー

- 配信・アーカイブを全画面またはシアターで見る視聴者
- デュアルモニタで別窓チャットを使う視聴者
- ニコ動風弾幕表示を好むが、必要時は入力もしたい視聴者
- Chromium 系または Firefox を使い、ストアから入れたいユーザー

MVP の対象外は、配信者向けの OBS オーバーレイ、モバイル、モデレーション業務の完全な代替とする。

### 3.2 表示モード（ユーザーが選択）

| モード                         | MVP        | YouTube ライブ／アーカイブ                                                  | Twitch ライブ／VOD                                                          |
| ------------------------------ | ---------- | --------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| オーバーレイパネル（積み上げ） | ○ 本番品質 | ○                                                                           | ○                                                                           |
| 別ウィンドウ（ポップアウト）   | ○ 本番品質 | ○（公式 URL、または `alwaysOnTop` 時にパネルメニューから開く Document PiP） | ○（公式 URL、または `alwaysOnTop` 時にパネルメニューから開く Document PiP） |
| 弾幕（右→左）                 | ○          | ○（トグル）                                                                 | ○（トグル）                                                                 |

利用者が別窓や Document PiP を閉じたら、パネル表示に戻す（ISS-031）。Document PiP に対応していない環境では、`alwaysOnTop` を利用できないと表示する。利用可否は機能の有無で判定する（ISS-032）。公式チャット UI が有効なら、PiP にもパネルと同じ公式チャットを表示する。YouTube のリプレイでは拡張機能のリストを表示する（ISS-033）。

MVP では主表示をパネルまたは弾幕から選べる。パネルを使うときに弾幕を重ねる場合は、設定で有効にする。

#### 混合チャット（YouTube ライブ ⇄ Twitch ライブ、ISS-034）

同じブラウザで YouTube ライブと Twitch ライブを開いているときは、視聴タブごとに相手サイトのライブタブを 1 件選べる。両サイトのコメントを 1 つの表示にまとめ、投稿元のロゴを添える。

取り込むコメントには 0〜120 秒の追加遅延を設定できる。接続時の初期値は `+0秒` とする。一時停止、シーク、広告の再生中は、取り込んだチャットの表示を止め、再開操作で表示を戻す。「場面を記録」を押して相手側のコメントを 1 件選ぶと、遅延の候補を表示する。候補を設定に反映するのは、利用者が「適用」を押したときに限る。

混合チャットは、パネル、通常別窓（拡張ページ `bridge-popout.html`）、Document PiP のいずれでも読み取り専用とする。切断したら、通常チャットの表示と元の投稿可否に戻す。初回の保証範囲はパネル、弾幕、通常別窓とする。混合チャットの Document PiP は対応環境で開ける場合に提供し、開けなければ通常別窓へ切り替える（ISS-005）。

### 3.3 投稿

- MVP: 通常チャットの **送信**
- 混合チャット接続中の画面（パネル・通常別窓・Document PiP）は **読み取り専用** とし、投稿 UI を出さない（切断で元の通常チャットへ復帰）
- 可能ならネイティブ入力の再利用または転送（ToS・絵文字・認証の一貫性のため）
- Post-MVP: スーパーチャット／Cheer の **送信**、モデ操作、チャンネルポイント自動回収（表示は §3.1）

### 3.4 NG / フィルタ（MVP）

すべての表示モードに適用する。

| 機能                                         | MVP             |
| -------------------------------------------- | --------------- |
| NG ワード（部分一致、任意で正規表現）        | ○               |
| ユーザー除外（表示名 / チャンネル ID 相当）  | ○               |
| Bot・`!command` 除外                         | ○（任意トグル） |
| ロール優先（モデ／メンバー等を間引き対象外） | ○（簡易）       |
| 翻訳・AI 要約                                | ×               |

### 3.5 設定・操作（MVP）

- 表示 ON/OFF、モード切替
- パネル位置・サイズ・透明度・フォントサイズ
- 弾幕: 速度、不透明度、密度／行数、縁取り
- 別窓: 位置・サイズ記憶
- ショートカットで表示トグル／モード切替
- 設定は端末内の `storage.local` に保存する。別窓の管理や混合チャットのタブ接続に必要なタブ ID、サイト種別、配信キー、表示ラベル、購読関係に限り、セッション中だけ `storage.session` に保持する。チャット本文、投稿者名、視聴者識別子はストレージに保存しない。混合チャットの接続先の選択と遅延設定は、ページのメモリでのみ保持する。設定の同期は任意とし、Post-MVP でもよい。
- UI 言語: `auto` + 約 44 言語（`AppLocale` / `locale-meta.ts`）。不足キーは英語フォールバック

詳細一覧: [settings-inventory.md](./settings-inventory.md)

### 3.6 プライバシー

- チャット／コメント本文を開発者のサーバーへ送らない
- アカウント不要
- アナリティクス SDK を MVP に入れない
- ストア用のプライバシーポリシーの公開は必須とする。

## 4. 明示的非スコープ（Post-MVP / 対象外）

- Kick 等の追加プラットフォーム
- ニコニコ生放送（旧 Phase 10–13 実装は 2026-11-15 に削除）
- YouTube 通常動画（スレッド型コメント・Shorts、2026-11-16 に廃止・ISS-027）
- OBS / 配信者向けブラウザソース
- 翻訳、AI 要約・キャラチャット
- チャンネルポイント／Drops 自動回収を売りにする機能
- モバイルブラウザ
- Twitch クリップ、ミニプレーヤー／ブラウザ映像 PiP への追従
- メンバー／サブ未加入時のゲート突破
- 複数の取り込み元を同時選択する統合タイムライン（3 チャンネル以上の同時統合）、映像解析等による自動場面同期、アーカイブ／VOD・通常動画を対象とした混合チャット（1 視聴タブにつき相手サイトライブ 1 件の手動選択・手動遅延補正のみ対象）

## 6. 通常 YT コメント（2026-11-16 廃止 — ISS-027）

2026-11-16 のオーナー指示により、YouTube 通常動画（スレッド型コメント・Shorts）への対応は廃止した。アダプタ・ポータル・拡張自前コメント別窓・設定・UI は削除し、通常動画では起動しない（ライブ判定は誤起動防止のため厳格維持）。

## 7. 非機能要件

- サイトごとの DOM の違いはアダプタ内で扱う。複数のセレクタを用意し、ページ構造の変化による不具合を検出できるようにする。
- Fullscreen API: オーバーレイを全画面要素配下へ再配置
- 高負荷時の表示上限・間引き
- Manifest V3、WebExtensions 互換（Chromium + Firefox）
- ストア審査: ホスト権限は **視聴・機能に必要な明示ホストのみ**（`<all_urls>` 禁止）
  - **必須**: `youtube.com` / `www.youtube.com`、`twitch.tv` / `www.twitch.tv`
  - **条件付き**（`twitch.thirdPartyEmotes` が ON のとき）: BTTV / FFZ / 7TV の API・CDN
  - 権限 API: `storage`（設定の `storage.local` 保存、別窓管理・混合チャット接続メタデータの `storage.session` 一時保持）、`windows`（公式チャット別窓・混合チャット拡張別窓）
  - （新規権限・host 権限・外部通信先の追加なし）
- 弾幕機能について、日本向けストア説明／README に非営利・非侵害の免責を明記（競合慣行）

## 9. 受け入れ基準（MVP 完了の定義）

1. YT ライブ／プレミア（チャット可の待機室含む）全画面でパネル表示・投稿・NG が動作する
2. Twitch ライブ全画面で同様に動作する
3. 弾幕トグルが YT ライブ・アーカイブ／Twitch で動作する
4. ライブ系（YT／Twitch）で別窓表示と位置記憶ができる
5. YouTube のアーカイブでシーク後もチャットがおおむね追従する（許容するずれは設定または文書で定義する）
6. Twitch VOD（Highlights 同経路含む）で再生・シーク後もチャットがおおむね追従する（同上。公式別窓／埋め込みは対象外）
7. 通常 YT 動画・Shorts で誤って起動せずページを壊さない（ISS-027）
8. Super Chat／Cheer／レイド等の **表示** がパネル／弾幕で落ちない（送信は不要）
9. Chrome と Firefox の両方で上記の主パスが通る
10. プライバシーポリシーと最小権限でストアスキャン／自己チェックを通過できる状態
11. YouTube ライブと Twitch ライブを接続すると、パネル、弾幕、通常別窓に投稿元のロゴ付きコメントが読み取り専用で表示される。追加遅延、中断時の非表示、手動補正、切断後の通常チャットへの復帰が動作する。混合チャットの Document PiP は、対応環境で開ける場合に提供する。

詳細母集団: [content-patterns-2026-11-15.md](./quality/content-patterns-2026-11-15.md)

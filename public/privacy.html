Privacy Policy / プライバシーポリシー

Fullscreen Chat Extension · Last updated: 2026-11-23

English

This extension does not collect, sell, or send your viewing history, chat/comment text, cookies, or account data to the developer.

  • Settings and NG lists are stored only in your browser (storage.local). Temporary session metadata for popout window management and mixed-chat tab connections (tab IDs, site type, stream identifier, and display label) may be held in storage.session while the browser session is active; chat messages, author names, and viewer identifiers are never written to storage.
  • When you use mixed chat between open YouTube Live and Twitch Live tabs, comments are relayed strictly inside your browser via extension runtime messaging for read-only display and are never sent to the developer or any third-party server.
  • Network traffic is limited to YouTube and Twitch pages you already visit, plus optional public BTTV / FFZ / 7TV emote APIs when that setting is on (enabled by default; can be turned off in Options). There is no analytics SDK and no developer telemetry endpoint.
  • Removing the extension deletes its storage according to your browser’s rules.
  • Contact: use the project’s GitHub Issues (or the store support link once published).

日本語

本拡張機能は、視聴履歴、チャットやコメントの本文、Cookie、アカウント情報を 収集・販売しません。開発者に送信することもありません。

  • 設定と NG リストは、端末内のブラウザ拡張機能用ストレージ （storage.local）にのみ保存します。 別窓の管理や混合チャットの接続に必要なタブ ID、サイト種別、配信キー、表示ラベルは、 ブラウザのセッション中に限り storage.session に保持する場合があります。 チャット本文、投稿者名、視聴者識別子はストレージに保存しません。
  • 開いている YouTube ライブと Twitch ライブのタブで混合チャットを使う場合、 拡張機能は読み取り専用の表示に必要なコメントのデータをブラウザ内でのみ中継します。 このデータを開発者や外部サーバーに送信することはありません。
  • 通信先は、利用者が開いた YouTube と Twitch のページに限ります。 エモートの設定を有効にしている場合は、BTTV、FFZ、7TV の公開エモート API にも接続します。 エモートの設定は初期状態で有効です。設定画面で無効にできます。 独自の解析・広告・テレメトリ用エンドポイントはありません。
  • 拡張機能を削除すると、ブラウザの規則に従って保存データも削除されます。
  • お問い合わせは GitHub Issues、公開後はストアのサポート欄でも受け付けます。

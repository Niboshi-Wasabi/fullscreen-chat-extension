Privacy Policy / プライバシーポリシー

Fullscreen Chat Extension · Last updated: 2026-11-15

English

This extension does not collect, sell, or send your viewing history, chat/comment text, cookies, or account data to the developer.

  • Settings and NG lists are stored only in your browser (storage.local / session helpers).
  • Network traffic is limited to YouTube and Twitch pages you already visit, plus optional public BTTV / FFZ / 7TV emote APIs when that setting is on. There is no analytics SDK and no developer telemetry endpoint.
  • Removing the extension deletes its storage according to your browser’s rules.
  • Contact: use the project’s GitHub Issues (or the store support link once published).

日本語

本拡張機能は、視聴履歴・チャット／コメント本文・Cookie・アカウント情報を 開発者へ収集・送信・販売しません。

  • 設定と NG リストは端末内のブラウザ拡張ストレージ （storage.local 等）のみに保存します。
  • 通信は利用者が開いた YouTube / Twitch への既存アクセス、および（設定オン時のみ） BTTV / FFZ / 7TV の公開エモート API に限ります。 独自の解析・広告・テレメトリ用エンドポイントはありません。
  • 拡張を削除すると、ブラウザの方針に従いストレージも削除されます。
  • 連絡先: 公開後はストアのサポート欄、または GitHub Issues。
